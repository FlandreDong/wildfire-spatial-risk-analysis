# California Wildfire Spatial Risk Analysis

## Overview
This project analyzes wildfire risk patterns related to the January 2025 California wildfire event using GIS and environmental datasets.

The goal of this project is to identify how terrain, vegetation, and environmental factors influence wildfire spread and spatial risk patterns.

## Technologies
- Python
- QGIS
- ArcGIS
- Spatial Analysis

## Methodology
1. Collected wildfire-related environmental and geospatial datasets
2. Processed and cleaned spatial data using Python
3. Built spatial models using GIS tools
4. Analyzed wildfire risk factors such as terrain and vegetation
5. Visualized wildfire risk zones and spatial impact patterns

## Example Output
Wildfire spatial risk maps generated using GIS tools.
